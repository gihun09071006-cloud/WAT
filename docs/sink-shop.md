# 소각처 · 상점 설계 — 인플레 완충의 능동 다이얼 (C4)

> **역할**: §15의 "능동 완충 레버"에 실체를 준다. 지금까지 경제 모델엔 `sink_rate` 숫자만 있었고 실제
> 소각처가 없었다. 이 문서 + `sink_shop.py`가 상점 카탈로그·수요·가격으로 그 숫자를 만들어낸다.
> 원칙(§15): 완충은 **상점가·신규 아이템**(합법)에 걸고 **WAT 환율**(불법·페그)엔 절대 안 건다.

## 1. 무엇을 태우나 (카탈로그)

게임 결정 로그의 4대 소비처. 전부 **랜덤 없음**(§5 방화벽: 랜덤 경로는 이 상점과 분리, 환전 불가 코스메틱만).

| 카테고리 | 예시 | 등급(§12) |
|---|---|---|
| 기체(plane) | 미식 스킨 · 제네시스 기체 | Mythic · Genesis |
| 조종사(pilot) | 정예 조종사 | Epic |
| 펫(pet) | 레전더리 펫 | Legendary |
| 코스메틱 | 도색 · 부스터 트레일 · 길드 문장 | Rare~Legendary |

등급 사다리 `Rare → Epic → Legendary → Mythic → Genesis`가 **수요 강도(pull)** 를 키운다. Spark는
구매 시 **소각**(§3) — 유통에서 사라진다.

## 2. 수요 모델 (`sink_shop.py`)

```
아이템 1개당 유저 기대 소비 = pull × price × exp( − price / (budget × k) )
   pull = appeal × 등급배수      budget = 유저가 기간당 버는 Spark
```

- 싼 아이템은 넓게 팔리고, 비싼 아이템은 드물게 팔린다.
- 유저당 총 소비 = Σ(아이템) , 예산 상한으로 캡 → **sink_rate = 소각 ÷ 발행**.

**결과 (예산 2,000 Spark 기준):**

| 상점 | sink_rate |
|---|---|
| 빈약(2종) | 17% |
| 기본(6종) | 46% |
| 풍부(8종) | 72% |

→ **매력적 소각처를 늘리면 소각이 단조 증가.** 이것이 인플레 흡수의 1차 레버.

## 3. ⚠️ 가격 다이얼은 단조롭지 않다 (모델이 잡은 핵심)

소비 곡선 `p·exp(−p/βk)` 는 **가격 = budget×k 에서 최대**다(sweet spot). 그 위에서 가격을 더 올리면
**총 소각이 오히려 준다** (수요가 죽어서):

| 가격 다이얼 | sink_rate |
|---|---|
| ×0.5 | 53% |
| ×1.0 | 46% |
| ×2.0 | 32% |
| ×3.0 | 23% |

> **§15 정밀화**: "유통 Spark가 불면 상점가 인상으로 흡수"는 **sweet spot 아래에서만** 참이다.
> sweet spot 위에선 인상이 흡수를 **줄인다**. 따라서:
> - **인플레 흡수 1차 레버 = 신규 매력 아이템 추가**(단조 증가, 안전).
> - **가격은 sweet spot 관리용** — 아이템이 너무 싸면(과소 소각) 올리고, 너무 비싸면(수요 死) 내린다.
> - 예외: 제네시스/고래용 아이템은 비탄력적이라 인상 흡수가 더 오래 유효(모델은 보수적으로 탄력 가정).

## 4. 왜 이게 안전한가 (§10·§15 재확인)

소각률을 바꿔 경제 모델에 주입하면:

| 상점 | sink | Y1 환율 | 유저 월$ |
|---|---|---|---|
| 빈약 | 17% | 160 Spark/WAT | **$1.73** |
| 기본 | 46% | 104 | **$1.73** |
| 풍부 | 72% | 54 | **$1.73** |

→ 소각을 늘리면 **환율(Spark/WAT)만 안정화**되고 **유저 달러 풀은 불변**(§10). WAT 환율·페그를
건드리지 않고 인플레를 잡는다. 규칙 3 위반 0.

## 5. 운영 규칙

- **전향적만**: 상점가·신규 아이템은 **다음 시즌 패치**로. 이미 산 아이템 재평가 금지(§15 발행 브레이크와 동일 원칙).
- **시즌 vs 영구**: 코스메틱은 시즌 로테이션으로 신선도 + 소각 다이얼 유지. Genesis는 영구 희소.
- **방화벽(§5)**: 랜덤 체스트/휠에서 나온 것은 이 상점에서 **환전 경로로 못 넘어간다**. 상점 구매도 Spark 소각일 뿐 WAT 지급 아님.
- **루트박스 주의(§ jurisdiction)**: Spark(가치재화)로 사는 랜덤 상자는 일부 관할서 규제 → 상점은 **확정 구매**(뭘 사는지 명확) 우선, 랜덤은 코스메틱·환전불가로 격리.

## 6. 연동 지점

- `sink_shop.sink_rate(catalog, budget)` → `economy_simulator`의 `sink_rate` 입력.
- 라이브 운영: 유통 Spark 관측 → 카탈로그/가격 조정 → sink_rate 재산출 → 환율 자동 안정화(손 안 대도 §4).
- 테스트: `test_sink_shop.py` (12개) — sweet spot·카탈로그 풍부함·달러 불변성 검증.
