# CPQ 검증 — 실험 설계서

> **왜 이것이 관문인가**: CPQ는 CLAUDE.md 전체에서 유일한 미검증 변수다(§9). 3년 모델 전 표가 이 값
> 하나에 매달려 있다. 이 문서는 **최소 비용으로 실제 CPQ 숫자를 뽑는 사다리**를 정의한다.
> 계산 도구: `cpq_model.py` · 관련 경제 모델: `economy_simulator.py`.

## 1. CPQ란 무엇이고 무엇에 갇혀 있나

광고주는 "CPQ"를 직접 부르지 않는다. CPQ는 그들이 부르는 단위(eCPM·CPC·CPA)에서 **삼각검증**해야 한다.

퀘스트 완료의 가치는 아래 밴드 안에 있다:

```
노출 하한(impression floor)  ≤  CPQ  ≤  액션 상한(action ceiling)
   passive view보다 비쌈                full acquisition보다 쌈
   (opt-in·완료·검증 = §1 테제)
```

가장 가까운 기존 포맷은 **rewarded video**(옵트인·끝까지 시청·인게임 보상) — QuestFi의 "부품 스캔"과
구조가 같다. 따라서 **rewarded eCPM이 1차 앵커**다.

## 2. 우리가 넘어야 할 숫자 (`cpq_model.py` 산출)

| 기준 | 값 | 출처 |
|---|---|---|
| **손익분기 CPQ** | **$0.0082** (fill별 $0.0073–$0.0107) | 유저 월 실질가치 $1 = economy_simulator |
| **목표 CPQ** | **$0.0300** | §8 가정 |
| 목표 도달 필요 eCPM (quest=1 view) | **$30** | 삼각검증 역산 |

### 삼각검증 결과 (planning anchor, 실측으로 대체 예정)

| 방법 | 시나리오 | CPQ | 손익분기 | 목표 |
|---|---|---|:---:|:---:|
| rewarded eCPM | global blended ($8) | $0.0080 | · | · |
| rewarded eCPM | tier-1 US ($18) | $0.0180 | ✓ | · |
| rewarded eCPM | tier-1 premium ($30) | $0.0300 | ✓ | ✓ |
| CPC | mid ($0.25) | $0.2500 | ✓ | ✓ |
| CPA @ 3% CVR | mid ($0.80) | $0.0240 | ✓ | · |

> **핵심 발견 (정직하게)**: **global-blended rewarded eCPM($8)은 손익분기($0.0082)를 아슬아슬하게
> 밑돈다($0.0080).** 즉 quest=1 rewarded view·글로벌 혼합 트래픽만으로는 모델이 성립하지 않는다.
> 성립시키는 레버는 셋: **(a) tier-1 편중 트래픽**, **(b) 완료 프리미엄**(검증된 완료가 passive view보다
> 비싸게 팔림 — 이게 §1 테제가 참이어야 하는 이유), **(c) quest당 광고 유닛 >1**("부품 스캔 10회" 설계가
> 여기 해당). CPC 렌즈로 보면 여유 있게 통과 → **퀘스트를 "클릭/전환"에 가깝게 설계할수록 유리.**

## 3. 실험 사다리 — 싼 것부터

### Tier 0 · 데스크 삼각검증 (완료)
- 도구: `cpq_model.py`. 비용 0, 산출: 위 밴드.
- 결론: 손익분기는 손 닿는 거리, 목표 $0.03은 프리미엄/멀티유닛/티어1이 필요. **다음 티어로 실측.**

### Tier 1 · 프록시 수요 측정 ★ 가장 싼 실측 (권장 시작점)
- **아이디어**: 자체 영업 없이 **기존 offerwall / rewarded 미디에이션 SDK**(타사 광고주 수요)를 최소 퀘스트
  프로토타입에 꽂고, **완료당 실제 매출($/completion)** 을 측정한다.
- 측정값: `realized_revenue_per_completion`, `fill_rate`, `completion_rate`.
- 이것이 곧 **하한 CPQ의 실측치** — "남의 광고주 수요"로 우리 완료 단위가 실제 얼마에 팔리는지 본다.
- 기간/비용: 2–4주, 프로토타입 1개 + SDK 연동. 영업 인력 불필요.
- 성공 판정: `$/completion ≥ $0.008` (손익분기) 관측.

### Tier 2 · 직접 CPQ 판매 (프리미엄 검증)
- 파일럿 광고주 3–5곳에 **CPQ 상품을 직접 판매** → 실제 체결가 + fill 측정.
- 검증 대상: Tier 1 프록시 대비 **완료 프리미엄**이 실재하는가(§1 테제의 상업적 증명).
- 기간/비용: 2–3개월, 초기 세일즈 + 리포팅 대시보드(ROI = 비즈니스 모델 그 자체, §1).
- 성공 판정: 체결 CPQ가 프록시 대비 유의미한 프리미엄, 목표 $0.03 근접.

## 4. 결정 게이트 (kill criteria)

측정된 CPQ에 따라 **사업의 성격 자체가 갈린다** (§9):

| 측정 CPQ | 판정 | 액션 |
|---|---|---|
| **< $0.008** | 모델 붕괴 | 파라미터(배분율·퀘스트당 유닛) 재설계 or 피벗. 현 이코노미로는 불가. |
| **$0.008 – $0.03** | "게임" (용돈 구간) | §8 포지셔닝대로 진행 — "돈 버는 게 아니라 게임". 안전. |
| **> $0.03** | "사업" 구간 | 유저 월 $ 급등. 포지셔닝·규제 스탠스 재검토(수익성 부각 시 증권성·사행성 재평가). |

## 5. 측정 위생 (안티봇 = CPQ 방어)

CPQ는 **품질 어텐션** 위에서만 유효하다(§1 생존 조건). 봇 완료가 fill에 섞이면 광고주 ROI가 붕괴하고
측정 CPQ가 거짓이 된다. 따라서 Tier 1부터 **완료 검증(안티봇 스코어)** 을 함께 계측한다 —
`bot_filtered_rate`를 §11 히든카드 지표로 노출.
