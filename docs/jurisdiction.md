# 타깃 관할 — 의사결정 프레임워크

> **목적**: B1(P0) 결정을 구조화한다. 한국 제외는 확정(§ CLAUDE.md 결정 로그). 이 문서는 **어디서 할지**를
> 고르기 위한 프레임 + 후보 비교 + 변호사에게 물을 질문이다.
> ⚠️ **법률 자문 아님.** 최종 결정 전 반드시 크립토·증권 전문 변호사 검토(§9). 정식 검토 전 기본값 용도.

## 0. 핵심 재구성 — "관할"은 하나가 아니라 3층 스택

이걸 분리하지 않으면 결정이 꼬인다:

| 층 | 질문 | 무엇을 정하나 |
|---|---|---|
| **① 토큰 발행자 / 재단** | WAT를 누가 발행·보유(트레저리·생태계 기금)하나 | 토큰 증권성·세금·온체인 |
| **② 운영사 / 팀** | 게임 운영·고용·광고주 계약은 어느 법인 | 인재·뱅킹·법인세·운영 편의 |
| **③ 유저 시장** | 어디 유저에게 서비스·마케팅하나 (어디를 지오블록) | 소비자·라이선스·마케팅 규제 |

대부분의 토큰 프로젝트: **①을 크립토-클리어 관할(발행자 격리)** + **②를 인재/뱅킹 되는 곳** + **③은 허용 시장만, 문제 관할은 지오블록.**

## 1. QuestFi 고유 규제 벡터 (어느 관할이든 이걸 물어야)

| 벡터 | QuestFi에서의 쟁점 | 우리 구조의 완충 |
|---|---|---|
| **WAT 증권성** | 발행·상장·FDV·트레저리 존재 | 유저에게 **판매 안 함**(플레이로 획득), 보상은 **광고 매출 분배**(투자 아님), **원금 리스크 없음** → 투자계약 징표 약함. 단 관할별 판단 필요 |
| **토큰 보상 게임** | 플레이 → 환전 가능 토큰 | 한국형 전면 차단은 예외적. 서구·걸프·SEA 대부분 게임 자체는 막지 않음 — 쟁점은 토큰 쪽 |
| **사행성 / 루트박스** | 체스트·Lucky Wheel(랜덤) | §5 방화벽: 랜덤 경로 **영구 환전 불가**. 단 벨기에·네덜란드 등은 **가치재화로 사는 루트박스** 자체 규제 → Spark로 구매 시 재검토 |
| **VASP 라이선스** | 토큰 운영·Spark↔WAT·지갑 제공 | 관할별 VASP/CASP 등록·라이선스 필요 가능 |
| **광고 · "earn" 마케팅 · 데이터 · 세금** | 인센 광고·수익 표현·프라이버시·보상 과세 | "보장 아님"·"원금 리스크 없음" 문구(이미 반영). 데이터는 GDPR 등 |

## 3. 왜 QuestFi 구조가 유리한가 (관할 무관 방어 자산)

- **매출 분배 ≠ 투자상품**: 재원이 뒷사람 자본이 아니라 광고 매출 → 폰지·투자계약 징표 약화.
- **원금 리스크 없음**: 예치·선구매 없음 → 소비자·투자자 보호 리스크 축소.
- **랜덤 방화벽(§5)**: 랜덤 보상은 환전 불가 → 사행성 분류 방어.
- **보장 아님 명시**: "월 $X 보장" 없음(규칙 3) → 오인 유도·수익 보장 광고 리스크 축소.

→ 이 넷은 **어느 관할 변호사에게든 내미는 방어 카드**다. 관할 선택이 이걸 무효화하지 않는다.

## 4. 잠정 권고 (변수 확정 전 기본값)

> 팀·예산·우선시장에 따라 갈리지만, QuestFi 같은 프로젝트의 흔한 합리적 기본형:
>
> - **① 발행자**: Cayman 재단 **또는** UAE (토큰 격리·트레저리)
> - **② 운영/HQ**: **UAE (VARA/ADGM)** — ①과 통합 가능, 세제·크립토 친화·허브
> - **③ 유저 시장**: 글로벌 허용 지역 + **유럽은 MiCA 정합** 시 정식 진입, **US·한국·문제 관할 지오블록**
>
> 즉 **"UAE 중심 + 필요 시 MiCA로 EU 확장 + US/KR 지오블록"** 이 무난한 출발점. 단 아래 변수로 바뀐다.

## 5. 결정을 좌우하는 미결 변수 (founder 입력 필요)

1. **팀·너의 물리적 위치** — 실질 활동·비자·뱅킹이 여기 걸림 (원격 분산? 특정국?)
2. **예산·진지도** — 풀 라이선스 HQ(UAE/스위스) vs 라이트 발행자(Cayman/BVI)+지오펜싱
3. **우선 유저 시장** — 글로벌 리테일? 특정 지역(SEA·중남미·유럽)? → ③ 규제가 여기서 갈림
4. **타임라인** — 지금 지오펜싱으로 소프트런치 후 라이선스 정비, vs 라이선스 먼저

## 6. 변호사에게 물을 정확한 질문 (관할별)

1. 우리 구조(플레이 획득 + 광고매출 분배 + 예치 없음)에서 **WAT가 증권/투자상품으로 분류되나?**
2. **플레이→환전 가능 토큰** 게임이 이 관할에서 서비스 가능한가? 등급·라이선스 요건은?
3. **Spark로 사는 랜덤 체스트**(환전 불가 코스메틱)가 루트박스/사행성 규제에 걸리나?
4. Spark↔WAT·DEX 경유·지갑 제공에 **VASP/CASP 라이선스**가 필요한가? 등록 vs 인가?
5. "부품 스캔"(인센 rewarded/offerwall)·"수익화 가능(보장 아님)" 표현이 **소비자·광고 규제**에 맞나?
6. 어느 유저 관할을 **지오블록**해야 하나 (US 주별 포함)?
